Spotify Widget — one-time setup

This page gets you a refresh token so the OBS widgets can read your currently playing song straight from the Spotify API, and writes it into settings.txt for you. Open this page in your normal browser (Chrome or Edge can save the file directly; Firefox and others download it), not in OBS.

Since February 2026 Spotify requires the app owner to have Spotify Premium; without it the app does not work even though this page hands out a token. Refresh tokens also expire after 6 months: when the widget stops picking up Spotify, run this page again.

Step 1 — Create a Spotify app

  1. Go to developer.spotify.com/dashboard and log in with your Spotify account (the one with Premium).
  2. Click Create app. Name/description can be anything (e.g. "OBS Widget").
  3. Under Redirect URIs add exactly: http://127.0.0.1:8888/callback
  4. Tick Web API, save, then copy the app's Client ID.
  5. If a friend will use this app with their own Spotify account, add their name and Spotify account email under Settings → User Management first. A development-mode app serves only the owner and the accounts listed there (up to five).

Step 2 — Authorize

Paste your Client ID and click Authorize. Spotify will ask you to approve, then send you to a page that fails to load (that's expected: nothing is listening on 127.0.0.1). If some page does load there, that's fine too. Either way, keep that tab open for Step 3.

open Spotify in a new tab

Step 3 — Paste the URL you landed on

From that tab, copy the entire address from your browser's address bar (it starts with http://127.0.0.1:8888/callback?code=…) and paste it here. The page then checks that Spotify actually lets this account use the app.

Step 4 — Save settings.txt

This is your settings.txt. It belongs in the same folder as the widget HTML files.

"Save into the widget folder" asks you to pick that folder once, checks that the widget files are in it, and writes settings.txt there, keeping any other settings you already had. Chrome and Edge only; in other browsers use Download and move the file into the folder yourself.

The widget keeps its own copy of the token as Spotify rotates it, so you only need to run this page again when you re-authorize. Each person needs their own settings.txt: a copied one stops working after its first use and shows the other person's music.

Troubleshooting — test a settings.txt

Widget stuck on "Nothing playing" with a reason underneath? Load the settings.txt from the widget folder (or paste its contents, yours or a friend's) and this page will do exactly what the widget does and show you Spotify's answers.
